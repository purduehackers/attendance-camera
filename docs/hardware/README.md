# Hardware

This directory documents the hardware for `attendance-camera`.

## [v11](./v11/README.md)

This is the current prototype: two padded hand-adjusted clamps, separate parts oriented for lower support use, an accessible tether attachment and corner lens bumpers. CAD files are [available here](../../cad/v11/). See the [hardware and assembly guide](./v11/README.md) and [print operator notes](../../cad/v11/PRINT-ADMIN-NOTES.md).

The design targets a Raspberry Pi 4, the Duckiedrone's Waveshare RPi Camera G and an INIU P51L-E2 battery. Ten installed pieces come from seven models; no coupons are included. Physical fit and loaded retention still need testing before overhead use. The [v10 mount review](./mount-review.md) explains the revision.

## Earlier revisions

Earlier native designs and reports are retained in `cad/` for reference. They are superseded and should not be used for printing. See the [revision history](../../cad/README.md).
